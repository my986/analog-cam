# HEISEI CAM

平成初期のビデオ映像を黎明期のネットに上げたような画質で、スマートフォンのカメラアプリ感覚で動画を撮れる Web アプリです。

- 時代（VHS原本 / RealVideo / ダイヤルアップ / ガラケー / 動画サイト）を選んで録画ボタンを押すだけ
- 劣化の強さは「軽・中・重」の 1 つだけ
- 日付スタンプは撮影日、時刻は 12H / 24H を切り替え可能
- すべてブラウザ内で処理（WebGL2 + MediaRecorder）。サーバー不要

## 使い方

カメラを使うため HTTPS で開く必要があります（GitHub Pages なら自動で HTTPS）。
スマートフォンで開いて「ホーム画面に追加」すると、アプリのように起動できます。

## ローカルで動かす

```bash
python3 -m http.server 8765
```

`http://localhost:8765` を開きます（localhost はカメラが許可されます）。
